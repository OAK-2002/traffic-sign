Road Sign Dictation Using Machine Learning
🚦 A Machine Learning-based Road Sign Recognition System 🚦

Project Overview
This project aims to recognize and classify road signs using Convolutional Neural Networks (CNNs). The model detects road signs in images and provides textual descriptions to assist drivers, self-driving vehicles, and traffic systems.

Key Features
✅ Real-time road sign recognition using OpenCV & CNNs
✅ Supports 42 types of traffic signs
✅ Flask & Gradio integration for a user-friendly web interface
✅ Trained using Kaggle's Traffic Sign Dataset
✅ Deployed using TensorFlow & Keras

Technologies Used
Machine Learning Model: CNN (Convolutional Neural Network)
Programming Language: Python
Frameworks & Libraries: Flask, TensorFlow, Keras, OpenCV, NumPy, Pandas, Gradio
Development Environment: Jupyter Notebook, VS Code
Activation Functions: ReLU, Softmax
